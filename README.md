# Simulador_Investimento_V2
Novidades: painel de notícias por tema com imagens, indicadores oficiais do BCB, impacto na carteira.
1. Envie TODO o conteúdo desta pasta ao repositório, incluindo `.github/workflows/news.yml` (crie pelo site se a pasta oculta não subir).
2. Settings > Actions > General > Workflow permissions: Read and write.
3. Actions > "Atualizar notícias" > Run workflow. Leia o log: cada fonte informa quantos itens trouxe e o final informa quantos têm imagem.
4. Settings > Pages > Deploy from branch > main / root.
Opcional: secret GNEWS_KEY (gnews.io) para mais volume.
